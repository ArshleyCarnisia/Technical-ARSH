Informacao

A programação web é a criação de desenvolvimento web sites e sistemas que abrimos em navegadores como Chrome ou Edge.
Ela usa linguagens de código para dar forma, cor e regras a páginas de internet, lojas virtuais e redes sociais.

HTML,CSS,JavaScript

O HTML (HyperText Markup Language, ou Linguagem de Marcação de Hipertexto) é a linguagem padrão usada para criar e estruturar páginas na internet.
Ele funciona como o esqueleto de um site, organizando textos, imagens, vídeos e links para que o navegador consiga exibi-los corretamente.

Para que serve o CSSMudar cores de textos e de fundosEscolher tipos e tamanhos de letrasOrganizar o layout e a posição dos elementosCriar animações e efeitos visuaisDeixar o site responsivo para celulares e computadores

JavaScript é uma linguagem de programação usada para criar conteúdos dinâmicos e interativos em páginas da web.
Junto com o HTML e o CSS, ele forma a base da internet moderna, adicionando vida, movimento e inteligência aos sites que você visita todos os dias.
